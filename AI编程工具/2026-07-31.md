### 1. Claude Code v2.1.220 今日发布 — 代码审查后台化 🔥

| 项目 | 内容 |
|------|------|
| **来源** | GitHub Releases / Claude Code Docs（2026-07-31） |
| **PM技能** | product-strategy, competitive-brief |

Claude Code 于今日发布 v2.1.220，距上一版本 v2.1.219（07-24）间隔 7 天。核心变更：

| 功能 | 说明 |
|------|------|
| **`/code-review` 后台子Agent化** 🔥 | 代码审查现在作为后台子Agent运行，不再填充主会话，同时保留堆叠斜杠命令作为审查目标 |
| **Emoji 短码自动补全** | 在提示输入中键入 `:heart:` 插入 ❤️，键入 `:hea` 显示建议 — 可通过 `emojiCompletionEnabled` 设置禁用 |
| **屏幕阅读器增强** | `--ax-screen-reader` 模式下，删除操作会播报被删除的文本（单词和行删除） |
| **Windows 路径修复** | 修复包含 `\u` 前缀段的 Windows 路径被损坏为 CJK 字符的问题 |
| **其他修复** | MCP 工具输出内存泄漏修复、Windows 自动更新失败恢复、登录到期警告从 5 天改为 3 天 |

**🫘 分析：** 这个版本虽然标记为"bug fixes and reliability improvements"，但 `/code-review` 转为后台子Agent 是一个值得注意的工作流改进。此前代码审查结果直接插入主会话，消耗上下文窗口。现在审查在后台运行，结果通过子Agent 状态行可见——这意味着你可以在等待审查完成的同时继续编码，Claude Code 的"多会话并行"能力继续深化。

## 🔥 三、底层技术与协议 ⭐️

### 1. Claude Code 系统提示词削减 80% 的工程方法 🔥

| 项目 | 内容 |
|------|------|
| **来源** | Magica / Anthropic（2026-07-24） |
| **PM技能** | product-strategy |

Anthropic 披露：Claude Code 从 Claude Opus 5 和 Claude Fable 5 的系统提示词中移除了**超过 80%** 的内容，编码评估未出现可测量的下降。

**关键方法：**

| 策略 | 说明 |
|------|------|
| **工具内指令** | 将持久指令移至工具描述中 |
| **技能按需加载** | 验证和代码审查信息放在单独的 Skills 中，Agent 按需调用 |
| **上下文工程指南** | 发布了面向客户构建 Agent harness 的上下文工程最佳实践 |
| **模型差异化** | 仅对高级模型（Opus 5、Fable 5）削减提示词；旧模型保留完整提示词 |

**设计哲学转变：**

> "The previous prompt's broad instruction to avoid comments has been replaced with a direction to match the surrounding code's comment density, naming and idiom."

Thariq Shihipar（Anthropic 技术团队成员）：早期模型需要示例和限制性指令，而新模型**被这些指令过度约束了**。

**🫘 分析：** 这不是简单的"删减字数"。它代表了一个工程范式转变：从"在提示词中告诉模型一切"到"让模型按需获取上下文"。这对企业客户的启示：你的 `CLAUDE.md` 文件也应该采用类似策略——专注于代码库特有的坑，而不是写模型自己能从仓库文件中发现的事实。

| PM技能 | product-strategy |

**与已有报告对比：** 07-29 报告提及了 Shihipar 的上下文工程观点，但未涉及 80% 削减的具体方法和技术细节。本期补充完整。
