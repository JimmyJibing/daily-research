**VentureBeat 独家专访要点：**

Den Delimarsky（协议核心维护者）：
> "以前你需要一个会话存储并管理会话 ID——如果你的一个计算 Pod 宕机了，突然所有请求都会失败。现在这不再是问题了。"

**已有企业先行部署：**
据 VentureBeat 报道，**Stripe、Block、Apollo、Cloudflare** 已在生产环境中部署新规范。这些公司的共同诉求是：将 MCP 服务器作为普通 HTTP 服务部署在标准 Kubernetes 集群上，无需粘性路由。

3. **竞争层**：Anthropic 作为 MCP 创建者，其 Claude Code 拥有最丰富的 MCP 生态。但 MCP 已捐赠给 Linux Foundation 下的 AAIF（联合创始方包括 OpenAI、Block），确保了**厂商中立性**——Codex CLI、Cursor、Copilot 都可以平等接入。
