### 2. Cursor Cloud Agent Hooks 全面升级：覆盖 Agent 对话全生命周期

| 项目 | 内容 |
|------|------|
| **来源** | https://cursor.com/changelog/side-chat / https://cursor.com/docs/hooks |
| **时间** | 2026-07 月（Side Chat 同期发布） |

**核心变化：**
- **新增对话级 Hooks**（此前仅有工具执行级）：
  - `beforeSubmitPrompt` — 在 Prompt 提交前进行安全/合规校验
  - `afterAgentResponse` / `afterAgentThought` — 追踪 Agent 的回复和推理过程
  - `subagentStart` / `subagentStop` — 控制子 Agent 的启停
  - `preCompact` — 观察上下文压缩时机
  - `stop` — 处理 Agent 完成事件
- **Hook 体系形成三层架构**：Agent Hooks（对话） + Tab Hooks（补全） + App Lifecycle Hooks（应用生命周期）
- **支持第三方工具兼容**：可直接加载 Claude Code 的 hooks 配置
- **Cloud Agent 全面支持**：所有 hooks 在云端 Agent 中同样生效

**🫘 对大土豆的参考价值：**
Cursor 的 Hook 体系正在成为企业级 AI 编程的安全与治理基础设施。结合上期 Anthropic 安全文章：
- **自修正循环**：`afterAgentResponse` + `beforeSubmitPrompt` 可以构建"Agent 输出 → 自动审查 → 修正"的闭环，减少人工审查负担
- **团队治理落地**：通过 `subagentStart` 限制子 Agent 的权限范围，实现类似 Anthropic 的"爆炸半径控制"
- **合规审计**：`afterAgentThought` 提供完整的推理链路，可满足企业内部代码审查的合规要求
- **与 Cursor Automations 联动**：Hooks + Automations 的组合可以实现 AI 编程工作流的全自动治理
