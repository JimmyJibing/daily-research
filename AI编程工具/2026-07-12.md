## 📊 核心趋势判断

过去两周，AI 编程工具生态呈现三个明确方向：
1. **Agent 从"单线程"走向"多会话协同"** — VS Code 和 Cursor 同步推出多聊天/并行 Agent 能力
2. **MCP 协议迎来史上最大重构** — 走向无状态（Stateless），影响深远
3. **AI 编程从桌面扩展到移动端** — Cursor 发布 iOS App，Agent 随时可用

## 🔥 精品内容

### 1. MCP 协议 2026-07-28 RC 发布：彻底走向无状态架构

| 项目 | 内容 |
|------|------|
| **来源** | https://modelcontextprotocol.io/specification/draft/changelog |
| **时间** | 2026-07-28（RC 预发布） |

**核心变化：**
- **移除协议级会话（Session）**：不再有 `Mcp-Session-Id`，`tools/list` 等端点不再按连接变化
- **完全无状态**：移除 `initialize`/`initialized` 握手，每个请求自带版本、身份、能力声明（`_meta` 字段）
- **新增 `server/discover`**：服务端必须实现此 RPC 来广播支持的协议版本和能力
- **统一订阅机制 `subscriptions/listen`**：替代 HTTP GET 端点和旧的 `resources/subscribe`，单一长连接推送
- **移除 `ping`、`logging/setLevel`**：日志级别改为请求级 `_meta` 参数
- **任务（Tasks）转为正式扩展**：`io.modelcontextprotocol/tasks` 重设计，支持轮询式 `tasks/get`
- **引入 MRTR（多轮往返请求）模式**：Server 返回 `InputRequiredResult`，Client 重试时补充信息，替代旧的 server-initiated requests

**🫘 对大土豆的参考价值：**
MCP 协议是当前 AI Agent 生态最重要的互操作标准。这次"无状态化"重构意味着：智能家居/物联网设备接入 AI Agent 的门槛大幅降低 — 不再需要维护长连接会话，每个请求自包含身份信息，更适合嵌入式设备场景。**建议关注 MCP 在 IoT 设备上的轻量实现方案。**

### 2. VS Code 1.128：多聊天代理会话 + Copilot Vision 正式发布

| 项目 | 内容 |
|------|------|
| **来源** | https://code.visualstudio.com/updates/v1_128 |
| **时间** | 2026-07-08 |

**核心变化：**
- **多聊天 Claude 代理会话**：单 Session 内含多个并行 Chat，可以对比方案、分支探索、并行执行
- **快速聊天（Quick Chat）**：无需打开工作区即可提问，`Cmd+K Cmd+N` 快速启动
- **只读 Subagent 聊天（Preview）**：Agent 派生子任务时，可以在 Agents Window 中查看子代理的实时执行过程
- **Copilot Vision 正式 GA**：可在 Chat 中粘贴/拖拽图片和 PDF，多模态编程正式可用
- **OS 级键盘快捷键**：VS Code 未聚焦时也能触发的全局快捷键

**🫘 对大土豆的参考价值：**
多会话 Agent 能力对团队协作场景价值极高 — 可以同时让 Agent 处理固件代码审查、UI 测试用例生成、文档编写等并行任务。Copilot Vision GA 意味着可以直接对 UI 截图进行代码级别的分析和修改建议，**TV/手机 UI 开发场景的调试效率将显著提升。**

### 3. Cursor：Side Chat + 对话搜索 + iOS 移动端

| 项目 | 内容 |
|------|------|
| **来源** | https://cursor.com/changelog/side-chat / https://cursor.com/changelog/ios-mobile-app |
| **时间** | 2026-07 月 |

**核心变化：**
- **Side Chat（侧边聊天）**：主会话旁开新对话，不中断主流程，支持 `/side`、`/btw` 命令快速创建
- **对话搜索引擎**：基于本地索引，`Cmd+K` 搜索数千条历史对话，`Cmd+F` 会话内搜索
- **Cursor iOS App 公测**：付费用户可在手机上启动 Cloud Agent、查看 Diff、Merge PR，支持语音输入
- **Remote Control**：从手机上接管桌面 Agent，电脑保持唤醒
- **Live Activities + 推送通知**：锁屏查看 Agent 进度，完成后收到推送

**🫘 对大土豆的参考价值：**
Side Chat 是"思维不打断"设计 — 开发中临时起意查资料、验证方案时不再打断主任务流，对长任务开发场景（如固件重构）体验提升明显。iOS App 让管理者可以在移动中审查代码、合 PR，对研究所负责人的碎片化时间管理有价值。

### 4. Cursor 企业级 MCP 管理 + Automations 升级

| 项目 | 内容 |
|------|------|
| **来源** | https://cursor.com/changelog/team-marketplace-updates / https://cursor.com/changelog/06-18-26 |
| **时间** | 2026-06 ~ 07 月 |

**核心变化：**
- **Team MCPs 统一分发**：管理员在 Dashboard 配置一次 MCP Server，自动分发到 Cloud Agent、IDE、CLI 全端
- **组织群组权限控制**：支持按 Organization Group 精细化控制 Marketplace 访问
- **`/automate` 技能**：用自然语言描述任务即可创建自动化 Agent
- **新触发器**：Slack 表情反应触发、GitHub Issue Comment、PR Review 等 5 种新事件
- **Computer Use 工具**：Automation 的 Cloud Agent 可独立操作浏览器生成 Demo

**🫘 对大土豆的参考价值：**
Team MCPs 统一管理解决了企业级 AI 工具部署的核心痛点 — 团队成员无须各自配置 MCP Server，管理员集中管控。这对研究所团队推行 AI 辅助开发标准化至关重要。Automations 的 `/automate` 技能让非开发人员也能创建自动化任务，降低 AI 工具使用门槛。

## 📈 趋势总结

1. **多 Agent 并发协作成为标配**：VS Code 多 Chat、Cursor Side Chat 都指向同一方向 — Agent 从单任务走向多任务并行
2. **MCP 协议重大转折**：2026-07-28 RC 无状态架构将深刻影响所有 AI 工具生态，值得持续跟踪
3. **移动端 AI 编程起步**：Cursor iOS 是首个真正可用的移动编程 Agent 客户端，开创了新品类
4. **企业级治理能力增强**：Team MCPs 统一分发、组织权限控制、Automation 模板化都指向 AI 编程工具的"企业就绪"
5. **国产云厂商接入开源 Agent 框架**：腾讯 TokenHub 加入 Cline，观察后续是否有更多国产厂商跟进
