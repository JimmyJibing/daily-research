## 一、本期关键更新

### 1. Cursor 3.9 Customize：插件/MCP/Skills 统一管理平台 | 🧩 AI编程"App Store"成形

**摘要：** Cursor 6月22日发布 3.9 版本，推出全新的 **Customize 页面**，将插件（Plugins）、MCP 服务器、Skills、子Agent、Rules、Commands、Hooks 统一到单一管理界面，支持用户级/团队级/工作区级三层配置。同时上线 **Marketplace 排行榜**，展示团队内最流行的插件/MCP/Skills，支持一键安装。**Plugin Canvases** 功能让插件提供预构建画布模板（如 Hex Canvas 数据可视化、Atlassian Canvas 实时看板）。**Team Marketplaces** 新增支持从 GitLab、BitBucket、Azure DevOps 导入插件仓库。这是 Cursor 从"工具"向"平台"转型的关键一步——构建开发者市场的双边网络效应。

**参考价值：** 对智能家居/TV/手机软件团队意味着：① 团队可封装内部编码规范、框架模板为 Cursor Plugin 或 Skill，在团队内分发给所有开发者，降低新人上手成本；② MCP 统一管理降低了接入内部工具链（CI/CD、设备测试平台）的门槛；③ 建议关注 Cursor Marketplace 生态成熟度，适时将团队最佳实践产品化为可复用组件。

---

### 2. Cursor Automations 升级：Agent 工作流全面自动化 | ⚡ CI/CD + Agent 融合

**摘要：** Cursor 6月18日大幅升级 Automations 功能：① **`/automate` 技能**——用自然语言描述任务，Cursor 自动配置触发器、指令和工具，零代码创建自动化；② **Slack Emoji 触发器**——在 Slack 消息上响应指定表情即可触发 Agent 自动化；③ **5 个新 GitHub 触发器**——Issue评论、PR review评论、PR review提交、Review线程更新、GitHub Actions 工作流完成；④ **Automation 支持 Computer Use**——Agent 可使用自己的计算机产生 demo 或工作产物。官方已发布"自动分类 GitHub Actions 失败"和"自动修复 PR review 意见"两个模板。这是 CI/CD 与 AI Agent 深度融合的信号——未来的 CI 流水线不再是固定脚本，而是由 Agent 动态决策。

**参考价值：** 对团队 CI/CD 流程有直接启发：① 可评估将 PR review、CI 失败排查等重复性任务交给 Automation Agent；② Slack 触发器的低门槛意味着 PM/设计师也能通过 Slack 触发编程任务，降低跨角色协作成本；③ 智能家居/TV 固件发版流程复杂，Automation Agent 可接管部分发版检查工作。

### 3. Cursor 云端 Agent 规模化：开发环境即产品 | ☁️ Agent Operations 新范式

**摘要：** Cursor 6月17日发布云端 Agent 重大升级：① **云端环境一键搭建**——10分钟内完成开发环境配置，Agent 在共享终端中实时展示进度，环境可快照复用，团队成员提交 `.cursor/environment.json` 即可共享；② **`/in-cloud` 子Agent**——在独立 VM 中启动云端子Agent，本机保持轻量和响应；③ **本地/云端无缝切换**——Agent 会话可在本地和云端之间转移，长任务推上云端，完成后拉回本地测试。Cursor 6月2日博客揭示：云端 Agent 日处理 5000万+ 操作、700万+ 工作流，**40%+ 的内部 PR 由云 Agent 生成**。关键架构洞察：开发环境即产品、使用 Temporal 保障持久执行、Agent/机器/对话三者解耦。

**参考价值：** 对团队开发基础设施有深远影响：① "开发环境即产品"理念可应用于团队——统一开发环境配置，降低环境不一致导致的协作摩擦；② 云端 Agent 模式对大型代码库（智能家居/TV 固件通常庞大）尤其有价值，长编译/测试任务可推上云端；③ Agent 规模化运营（50M+操作/天）的经验可借鉴到智能家居设备的云端管理。

### 4. Trae Work Design Mode：字节系视觉驱动编程入局 | 🎨 双雄对决

**摘要：** Trae 继 6月9日推出 Trae Work（"让 TRAE 替你工作"）后，6月25日发布 **Trae Work Design Mode**，支持在浏览器中通过点击、框选和语音指令驱动 Agent 修改 UI 代码。这与 Cursor 6月5日的 Design Mode 形成直接对标，表明"视觉驱动 UI 编程"正在成为行业标配。此外，Trae 5月6日已发布 SOLO Mobile，将自主编程 Agent 扩展到移动端。Trae 的多产品矩阵（IDE → Trae Work → SOLO Mobile）覆盖了从桌面到移动、从辅助到自主的全谱系。

**参考价值：** 对智能家居 App/TV 界面开发：① Design Mode 已成趋势（Cursor + Trae 双入局），建议尽快在团队前端开发流程中试点；② Trae Work 的"自主工作"定位对小团队尤其有吸引力——智能家居 App 的 UI 调整、设备面板迭代可考虑由 Agent 自主完成；③ 关注 Trae 和 Cursor 在 Design Mode 上的差异化竞争，选择更适合团队技术栈的方案。

### 5. Claude Code 2.1 系列：Windows 原生支持 + 可靠性大幅提升 | 🪟 Windows 生态补强

**摘要：** Claude Code 6月下旬密集发布 2.1.187–2.1.195 版本，关键更新：① **Windows 原生安装**（WinGet: `winget install Anthropic.ClaudeCode`），同时支持 PowerShell 和 CMD 一键安装；② **沙箱凭证隔离**（`sandbox.credentials`）——阻止沙箱命令读取密钥文件和环境变量；③ **`/rewind` 命令**——支持从 `/clear` 之前的对话恢复；④ **CPU 使用率降低 ~37%**——通过合并文本更新到 100ms 间隔；⑤ **组织级模型限制**——企业可限制可用的 AI 模型；⑥ **MCP 可靠性改进**——能力发现自动重试、OAuth 头重连、HTTP 404 错误提示增强；⑦ **自动模式改进**——新增 `classifyAllShell` 设置，将全部命令路由到分类器。Claude Code 的定位已从"终端 AI 助手"升级为"企业级 AI 编程平台"。

**参考价值：** 对国内以 Windows 为主的开发环境：① Claude Code 的 WinGet 安装支持和 Windows 持续优化，使其成为 Windows 平台上 VS Code/Cursor 之外的有力补充；② 沙箱凭证隔离 + 组织级模型限制，为企业引入 AI 编程提供了安全合规基础；③ CPU 优化（-37%）对资源受限的开发机更友好；④ Claude Code 的 MCP 深度集成与 OpenClaw 的 MCP 生态可以互补。
