## 一、核心动态（5 条）

### 1. 🔥🔥 Cursor 收购 Continue 并关闭产品 — 开源 AI 编程最大整合（2026.6.16）

Cursor（Anysphere）完成对 **Continue.dev** 的收购，随即宣布 **关闭 Continue 产品线**：

- **收购时间线**：6 月 11 日 The New Stack 曝光 → 6 月 16 日 Continue 官网确认 → 6 月 19 日发布最终版 v2.0.0-vscode
- **关闭节奏**：计费已停用 → **7 月 15 日删除所有云端用户数据** → GitHub 仓库冻结为只读
- Apache 2.0 代码仍可用，可 fork 但无维护
- Continue 曾是 VS Code 上最流行的**"自带模型"开源 AI 编程助手**，GitHub 34,300+ 星标

**战略意义：**
- Cursor 正在通过收购消除"自带模型"（BYOM）生态的竞争——Continue 是 Cursor $20/月定价的最大"免费替代品"
- 结合此前 Cursor 被传已被 SpaceX 收购，Anysphere 正在构建 AI 编程的垂直整合帝国
- 社区反应两极：开源开发者愤怒，商业用户理解但担忧单一厂商锁定

**对大土豆的影响：**
- Continue 用户需在 7 月 15 日前导出数据，团队若有使用应立即迁移
- 推荐替代路径：Cline（开源+模型无关+VS Code 插件）或直接转向 Trae（免费+中文最优）
- Continue 关闭佐证了一个趋势：**AI 编程工具正在从"百花齐放"走向"巨头整合"**，选择工具时必须评估厂商锁定风险

### 2. 🔥 Google Antigravity 2.0 全面平台化 — 免费五面一体（2026.5.19 I/O 发布）

Google I/O 2026 上 Antigravity 2.0 不是版本更新，而是一次 **"品牌吞并"式的平台重组**：

**四个产品统一为一个品牌：**
- 🖥️ **Desktop App**：独立桌面应用（VS Code fork，但大幅改造）
- ⌨️ **CLI (`agy`)**：Go 语言编写的终端 Agent，替换 Gemini CLI
- 🧩 **SDK**：开发者可用 Antigravity 的 Agent 引擎构建自定义 Agent
- ☁️ **Managed Agents（Gemini API）**：云端 Agent 托管平台
- 🏢 **Gemini Enterprise Agent Platform**：企业级部署，集成 Google Cloud

**被废止的旧产品（已过期/将过期）：**
- ❌ Gemini CLI → 2026 年 **6 月 18 日**迁移截止，已强制
- ❌ Code Assist IDE 插件 → 合并入 Antigravity
- ❌ 旧版 Agent 工具 → 全部迁移

**核心能力：**
- **Agent Manager**：任务控制台，启动/监控/审批并行 Agent
- **Plan Mode**：先审批蓝图再执行代码（Review-Driven Development）
- **Persistent Sessions**：Agent 记住全代码库上下文，跨错误修复保持连贯
- **默认模型 Gemini 3.5 Flash**：比同类工具快 4 倍
- 支持 **Claude Sonnet 4.6 / GPT-OSS-120B** 等多模型切换
- **完全免费**

**趋势判断：**
- Google 正在用"免费"闪电战抢占 AI 编程入口——Antigravity 不只是 IDE，它是 Google 开发者生态的 AI 层
- 局限性：仍在 Public Preview，无 GA 日期；工作区本地索引无法聚合多仓库上下文（不适合微服务架构）
- 对大土豆团队：Antigravity 的 **SDK + Managed Agents** 可能成为内部工具链的基础设施，尤其适合智能家居多设备协同的场景编排

### 3. 🔥 GitHub Copilot Token 计费正式实施 — 开发者大规模迁移（2026.6.1 生效）

6 月 1 日 GitHub Copilot 从固定订阅制正式转为 **Token 用量计费（AI Credits）**，影响远超预期：

**定价变化：**
| 方案 | 旧定价 | 新定价 |
|------|--------|--------|
| Individual | $10/月不限量 | $10/月获得 AI Credits 额度，超出按 token 计 |
| Business | $19/月 | 同价但按 token 消耗 |
| Enterprise | $39/月 | 同价但按 token 消耗 |

**社区反应（Reddit r/GithubCopilot / GitHub Discussions）：**
- 热门帖标题："End of an Era [June 1, 2026]"
- 大量用户报告月费从 $10 飙升至 $40-80
- Agentic 工作流（多文件编辑、长对话）是 token 消耗大户，成本暴增
- GitHub 暂停了 Pro / Pro+ 新用户注册

**引发的迁移潮：**
- 向 **Cline + OpenRouter/本地 Ollama** 迁移（完全免费或按量低价付费）
- 向 **Trae** 迁移（基础版永久免费，Pro 仅约 $10/月）
- 向 **Antigravity** 迁移（完全免费，多模型支持）
- 向 **Claude Code** 迁移（虽按量但推理能力更好）

**对大土豆的影响：**
- ⚠️ 假如团队在用 Copilot Enterprise，**立即审计月费变化**——Agent 模式的 token 消耗可能已暴增 3-5 倍
- 国内团队建议优先评估 Trae（免费+中文最优），长期考虑 Cline + 本地 Ollama（数据不出境）
- Token 计费是行业趋势—Cursor 大概率也会跟进，提前锁定免费/固定价工具做备份

## 二、技术趋势分析

### 1. AI 编程工具进入"整合淘汰期"

2026 Q2 标志着 AI 编程工具从"百花齐放"进入"残酷淘汰"阶段：

- **Cursor 收购 Continue** → 消除"Bring Your Own Model"生态最大的免费替代品
- **Google Antigravity 2.0** → 废止 3 个独立产品，统一为 1 个品牌
- **GitHub Copilot Token 计费** → 用价格杠杆筛选"高价值用户"
- **Trae 推出企业版** → 从中国市场的领先地位向商业化变现过渡

**结论**：未来 6-12 个月，AI 编程工具将形成"三巨头"格局：Cursor（商业化）、Antigravity（平台化）、Trae（中国化），而开源方向由 Cline/Roo Code 支撑。选择工具不再只是"好不好用"，更是"会不会被锁定/会不会被关闭/会不会涨价"。

### 2. 从"编辑器插件"到"平台化开发基础设施"

Antigravity 2.0 的 SDK + Managed Agents 和 Cline 的 SDK 发布表明一个趋势：AI 编程工具正在从"帮你写代码"升级为"帮你编排开发流程"。

**平台化意味着：**
- 团队可以基于 Agent 引擎构建自己的开发工作流
- Agent 可以嵌入 CI/CD、Code Review、自动化测试等既有流程
- Skills/Rules/Memories/Hooks 成为 Agent 可编程的"操作系统原语"

### 3. Token 计费引发"效率经济学"

Copilot 计费模式转变迫使团队重新思考：**每次 AI 调用值多少钱？**

- 简单补全 → 用便宜模型/本地模型
- 复杂重构 → 用顶级模型但精打细算 prompt
- Agent 多文件编辑 → 评估"手工做 vs AI 做"的时间/金钱 trade-off

这对智能家居/TV 这种"大量重复但有规律"的代码场景影响最大——引入 AI 前需要做 **ROI 测算**。

## 三、企划洞察

### 💡 机会 1：智能家居/TV 领域的 AI 编程技能包

Trae Skills + Cline SKILL.md 的机制为垂直领域定制提供了技术基础。可以构建：

- **AOSP/TV 定制 Skill**：Android TV 编译链、系统签名、OTA 打包流程的 AI 知识包
- **Matter 协议 Skill**：智能家居 Matter 标准的代码生成/验证模板
- **嵌入式交叉编译 Skill**：ARM/RISC-V 交叉编译链的 Cline/Trae 配置
- **多屏 UI 适配 Skill**：TV 大屏 + 手机 + 手表的设计规则和代码生成

**建议**：先选一个场景（如 AOSP TV 定制），用 Cline SKILL.md + 本地 Ollama 做一个 MVP，验证效果后再扩展到其他场景。

### 💡 机会 2：Token 经济下的本地 AI 编程方案

Copilot 涨价引发的迁移潮说明：**企业正在寻找"不按 token 计费"的 AI 编程方案**。

- **Cline + Ollama + DeepSeek Coder**：完全免费，代码不出境
- 适合场景：安全敏感代码（固件/系统/密钥相关）
- 适合团队：已有机房/GPU 资源的中型团队

对大土豆的参考：内部团队可试点"日常编码用 Trae（免费），安全敏感编码用 Cline + Ollama（本地），复杂重构才用 Claude Code（按次）"的三级方案。

### 💡 机会 3：Agent 编排平台 — Antigravity SDK 的启发

Antigravity 2.0 的 SDK 允许将 Agent 引擎嵌入自有基础设施。类比到智能家居场景：

- **智能家居测试 Agent**：自动部署固件到测试设备 → 跑自动化测试 → 回传结果
- **TV App 商店审核 Agent**：自动检查提交的 TV 应用是否符合上架标准
- **多设备协同场景编排 Agent**：生成并验证智能家居场景的自动化规则

**建议**：关注 Antigravity SDK 的 GA 时间，在内部做一个 POC。

### ⚠️ 风险提示

1. **Continue 关闭的启示**：选择开源工具时评估"被收购风险"——Cline 目前是最安全的开源选项（Apache 2.0 + 社区足够大）
2. **Trae 数据出境**：有报告指出 Trae 在 opt-out 后仍上传数据，企业用户需关注合规
3. **Antigravity 非 GA**：仍是 Public Preview，不建议在生产环境依赖
4. **Copilot 价格不确定性**：Token 计费后每月费用不固定，难以做预算规划
