### 1. VS Code 1.130 发布 — Agent Host 正式铺开，三 Harness 全覆盖 ⭐️⭐️⭐️

| 项目 | 内容 |
|------|------|
| **来源** | https://code.visualstudio.com/updates/v1_130 |
| **发布时间** | 2026-07-22 |
| **PM技能** | competitive-brief, product-strategy |

VS Code 1.130 于 07-22 发布（上期 07-22/07-23 报告未覆盖），是 1.129 AHP 架构发布后的首个深度落地版本。核心进展：

**Agent Host — 从实验性到正式铺开：**
- Agent 会话运行在独立专用进程，可被多个 VS Code 窗口同时连接和渲染
- Copilot Agent 底层统一用 **Copilot SDK**（`@github/copilot-sdk`），与 Copilot CLI、GitHub Copilot 独立 App 行为对齐
- 用户需手动开启 `chat.agentHost.enabled` 并选择 harness（Copilot/Claude/Codex）

**Assisted Tool Approvals — Agent 自主判断风险等级 🔥：**
- 设置 `chat.assistedPermissions.enabled`
- LLM 评估每个工具调用的风险级别，决定"自动执行"还是"需要用户审批"
- 减少长周期 Agent 任务中的审批中断频率（此前报告多次提及 Agent 审批过多是痛点）

**Agents Window 三项改进：**
- **文件级 diff 统计**：每个文件的 Header 显示行插入/删除数
- **紧凑多文件 diff**：减少空白，文件头/行号/未修改区域控件统一对齐
- **紧凑快速聊天**：快速聊天使用单行紧凑行，与完整会话区分

**Worktree 支持扩展到所有 Harness（Copilot + Claude + Codex）🔥：**
- 此前仅 Copilot harness 支持 worktree 隔离
- 1.130 中 Claude 和 Codex harness 也支持 worktree — 同一仓库可并行跑多个 Agent 会话处理不同功能
- 这标志着 AHP 协议实现了真正的"harness 无关性"

**其他更新：**
- Chat Timestamps（`chat.verbose` 开启后显示请求/响应时间戳和耗时）
- Copilot Business/Enterprise 聚合 AI Credit 用量面板
- 终端 Git diff 可点击文件链接（支持 `diff.mnemonicPrefix`）
- **TypeScript 7 正式编译 VS Code**（工程级升级）

**🫘 分析：** 1.130 最大的信号是"三 Harness 平等化"——Claude 和 Codex 现在享有与 Copilot 同等的 worktree 隔离支持。Microsoft 的 AHP 协议正在兑现"Agent 无关"的承诺。Assisted Tool Approvals 如果效果好，将实质性提升 Agent 编码体验（减少审批摩擦）。

### 2. Cursor Router 正式上线 — 智能模型路由，企业成本降 30-50% ⭐️⭐️⭐️

| 项目 | 内容 |
|------|------|
| **来源** | https://cursor.com/blog/router |
| **PM技能** | competitive-brief, market-sizing |

Cursor 发布 **Cursor Router**，一个面向团队和企业的智能模型路由器。

**核心机制：**
- 在模型运行前对每个请求进行**分类**，按任务复杂度、上下文、领域自动路由到最优模型
- 简单任务 → 经济模型，复杂/长期任务 → 前沿推理模型
- 基于 **60 万+真实请求**训练，在数百万请求的在线 A/B 测试中验证
- 评估指标：用户满意度（AFC）+ 代码保留率（Keep Rate）
- **缓存感知**（cache-aware）：路由决策会考虑缓存未命中成本

**性能数据：**

| 对比 | 节省 | 备注 |
|------|:---:|------|
| Auto Intelligence vs Opus 4.8 | ~0% 成本 | 满意度提升 **15%** |
| Auto Intelligence vs Fable 5 | **~60%** | 满意度持平 |
| Auto Balance vs Opus 4.8 | **~36%** | 满意度高于 Opus 4.8 |
| 企业实测（vs 全部 Opus 4.8） | **30-50%** | 质量无下降 |

**单次 Commit 成本对比：**

| 方案 | 每次 Commit 成本 |
|------|:---:|
| Cursor Router Intelligence | **$6.76** |
| Cursor Router Balance | **$4.63** |
| Opus 4.8（单一模型） | $7.34 |
| GPT-5.6 Sol（单一模型） | ~$6.76（但满意度低） |
| Fable 5（单一模型） | **$12.69** |

**三种模式：**
- **Intelligence**: 前沿质量，匹配最贵的模型性能
- **Balance**: 日常驾驶的前沿模型质量
- **Cost**: 好质量，最大化 token 节省

**管理控制：** 管理员可按团队/组启用、限制模式、设置默认值、允许/阻止特定模型。覆盖桌面、Web、iOS、CLI、SDK。

**与已有报告对比：** 全新内容。此前报告覆盖了 Cursor Slack 集成、Side Chat、iOS App，但 Cursor Router 是商业模式创新层面的大动作。

## 🔥 二、AI 编程 CLI 与 Agent 工具

### Claude Code 密集迭代 — 多项质量改进

| 项目 | 内容 |
|------|------|
| **来源** | https://github.com/anthropics/claude-code/releases |
| **PM技能** | competitive-brief |

Claude Code 近期版本持续密集迭代，本期重点改进：

**功能改进：**
- `/code-review` 改为后台子 Agent 运行，不再填充对话历史，可对堆叠斜杠命令进行审查
- MCP 连接失败时显示 HTTP 状态码和错误文本，MCP 配置值中的隐式前后空格发出警告
- `/ultrareview` 改进：支持描述性参数（如 "review my auth changes"），错误反馈可让 Claude 修正无效参数
- emoji 短码自动补全（`:heart:` → ❤️）
- 子 Agent 并发上限（默认 20，可配置 `CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS`）
- 子 Agent 默认不再嵌套生成孙子 Agent

**安全与稳定性改进：**
- Agent frontmatter hooks 要求工作区信任
- 改进沙箱命令限制（IDE 交互场景）
- 监控目录删除/移动时的崩溃修复
- 自动 compact 修复（Opus 4.8 Bedrock 上的问题）
- 转录写入失败的警告机制

**auto-mode 改进：**
- `dangerous-rm`/`background-&`/`suspicious-Windows-path` 检查不再弹出权限对话框，由 auto-mode 分类器裁决
- plan mode + auto 组合：Bash 命令不再要求审批
- 切换模型时宣布 fast mode 变化

**企业/平台改进：**
- Gateway 计费修复：Bedrock 应用推理配置文件 ARN 按配置模型价格计费
- 托管设置中 benign feature/cost 开关不再触发审批
- 服务器管理的设置优化

**与已有报告对比：** 全新内容。此前报告未跟踪 Claude Code 的版本级迭代。

## 🔥 五、热点趋势与开发者舆论

### 1. "AI 不替代人，但替代工作" — 硅谷叙事转变

Patreon 裁员声明中"AI doesn't replace humans, but AI replaces the work humans do"一语道破了当前科技行业的核心矛盾：
- 公司层面：AI 提高效率 → 需要更少的人 → 裁员
- CEO 层面：不是我们的错，是技术变革
- 员工层面：结果就是失去工作

The Verge 读者评论区的经典回复："AI doesn't replace humans, but AI replaces the work the humans do. Got it."

**对编程行业的影响：**
- vibe coding 让非程序员做应用 → 入门级编程岗位可能减少
- Cursor Router 让企业用更少成本获得前沿代码质量 → 高级开发者的"成本溢价"被削弱
- 但 On the other hand，AI 编程工具的用户群在扩大（从专业开发者扩展到所有人）→ 编程工具的 TAM 在增长

### 2. OpenAI vs Apple 法律战升级

| 来源 | The Verge（2026-07-23） |
|------|------|
| **PM技能** | porters-five-forces |

- Apple 起诉 OpenAI，指控前员工窃取商业机密
- Apple 向约 40 名前员工发出法律警告
- The Verge 评论：OpenAI 承受不起另一起诉讼，尤其是与 Apple 这种体量的公司

对 AI 编程工具的间接影响：如果 OpenAI 被拖入与 Apple 的长期诉讼，可能分散其在 Codex/Codex CLI 上的投入，为 Anthropic（Claude Code）和 Cursor 提供竞争窗口。

### 3. 开发者社区讨论焦点

- **Cursor Router 引发"模型锁定"讨论**：有开发者担心 Router 可能导致团队依赖 Cursor 的模型选择判断（"你不知道自己在用什么模型"），但也有人认为这正是企业需要的——"我不需要知道用哪个模型，我只需要好的结果"
- **VS Code 三 Harness 平等化**：Claude Code 作为 VS Code 中的一等公民（worktree 隔离、Agent Host 支持），引发"Anthropic 是否会被 Microsoft 收编"的猜测
- **MCP 1.0 倒计时 4 天**：社区期待值高，特别是 MCP 规范中 Agent 权限控制的标准化
