### 1. 🧠 Xiaomi Miloco 2.0 开源：小米先交卷了—— Agent 时代智能家居终于"智能"了（🆕 本期重点）

**来源/企业：** 小米 / 智东西 (2026年6月)

**摘要：**
小米正式发布并开源 **Xiaomi Miloco 2.0**，一套面向未来的全屋智能 AI 开源方案。这是**全球首个实现 AI 主动服务 + 家庭记忆的智能家居解决方案**，让 AI Agent 真正拥有"眼睛、耳朵和记忆"。四项核心能力：(1) **多模态感知** — 摄像头+声音传感器协同判断"水烧开但人不在厨房"等复杂场景；(2) **主动智能** — 感知加班晚归送慰问、生日自动布置灯光+电视+音箱惊喜；(3) **持续任务** — 长期监测孩子坐姿/看电视时长/老人夜间动向，条件触发自动干预；(4) **家庭记忆** — 记住每个家庭成员的偏好（灯光色温、坐姿习惯、腰病史），提供个性化服务。

关键架构：Miloco 部署在本地，米家设备作感知入口 → 云端 omni 多模态大模型分析 → Agent（如 OpenClaw）做决策 → Miloco 联动全屋设备执行。**所有原始数据保存在本地，30天自动清理，与 Agent 完全隔离**。部署门槛极低：一台电脑 + 米家账号 + 一个摄像头 + API Key 即可。

这是继 2025年11月 Miloco 1.0 后仅7个月的重大升级，从"设备互联"进化到"系统级 Agent"。

**企划建议：**
- **Miloco 2.0 定义了"Agent 时代智能家居"的参考架构**：感知层（多模态传感器）+ 记忆层（家庭档案）+ 决策层（Agent）+ 执行层（设备联动）—— 电视品牌应以此四层模型重新设计大屏在智能家居中的角色，尤其是"家庭记忆可视化"和"持续任务状态面板"
- **OpenClaw 集成是关键信号**：Miloco 选择接入 OpenClaw 而非自研 Agent 框架 → 说明 "专业感知中间件 + 通用 Agent" 是智能家居 AI 的正确分工。电视 SoC 可以考虑集成类似 Miloco 的多模态感知中间件，让任何 AI 助手都能"看懂家"
- **家庭记忆 = 智能家居的"用户画像 2.0"**：不再只是行为日志，而是跨设备、跨时间的语义化家庭知识图谱 → 电视作为"家庭数据中枢"应主导家庭记忆的构建和呈现
- **隐私安全是竞争壁垒**：小米强调本地存储 + 30天清理 + Agent 隔离 → 这是 Apple HKSV 路线与 Google 云端 AI 路线的中间道路，值得国内品牌参考
- **"Agent 时代智能家居"叙事已成型**：Google 有 Gemini for Home，Apple 有 Apple Intelligence，小米有 Miloco + OpenClaw → 电视品牌必须回答："大屏在 Agent 驱动的智能家居中是什么角色？"

### 4. 🔐 Eufy FamiLock 人脸/掌静脉识别智能锁 + Matter：生物识别进入 Matter 生态（🆕）

**来源/企业：** Anker/Eufy / The Verge (2026-06-11)

**摘要：**
Anker 旗下 Eufy 发布三款新的 Matter 兼容智能锁，首次将**人脸识别和掌静脉识别**带入 Matter 生态：(1) FamiLock E32 ($139.99) — 入门级，指纹识别；(2) E40 ($299.99) — **人脸识别**，无需接触即可开锁；(3) E35 ($299.99) — **掌静脉识别**，比指纹更安全（活体检测/不可复制）。三款锁均支持 Matter 协议，首批通过 Home Depot 销售，后续上架 Amazon。

这是 Matter 协议首次覆盖**高端生物识别智能锁**品类。此前 Matter 智能锁多为基础款（PIN码+蓝牙），Eufy 将人脸/掌静脉识别带入 Matter 生态，标志着 Matter 从"基础连接"走向"高附加值设备"。

**企划建议：**
- **Matter + 生物识别 = 智能锁从"单品"升级为"全屋入口"**：人脸识别锁可触发"回家场景"——锁认出了谁，全屋自动切换为该家庭成员的偏好（灯光/温度/音乐/电视开机频道）
- **掌静脉识别是下一代门锁技术方向**：比人脸隐私友好（不需存储面部数据）、比指纹卫生（非接触）、比 PIN 码安全 → 国内品牌（小米/鹿客/凯迪仕）应跟进 Matter + 掌静脉锁
- **Matter 认证正从"加分项"变为"必选项"**：Eufy 选择在 Home Depot 首发（DIY 用户聚集地）→ Matter 兼容 = 降低安装门槛 + 提高跨平台吸引力

### 6. 🎯 Google Home 摄像头视觉自动化：自然语言描述触发全屋场景联动（🆕）

**来源/企业：** Google / 9to5Google (2026-05-27)

**摘要：**
Google Home 推出**摄像头视觉场景理解驱动的自动化触发器**：用户可用自然语言描述摄像头中的特定画面场景，作为全屋自动化触发条件。例如："红色 BMW 驶入车道"→ 自动开车库门；"Amazon 快递送达"→ 发通知；"浣熊靠近垃圾桶"→ 开灯驱赶。支持 Familiar Faces 结合特定人物识别（"张三下车"→ 开灯迎客）。

这是 AI 视觉从"识别物体"到"理解场景语义"的质变——不再只是"检测到运动"，而是"知道具体发生了什么"。该能力同时支持 Nest Cam 和第三方"Gemini built in"摄像头（如 Walmart onn 系列），意味着 $35 的摄像头也能用上高级 AI 自动化。

**企划建议：**
- **"摄像头即全屋传感器"——比红外/门窗传感器更强大的感知维度**：传统传感器只能检测"有人/无人"，摄像头 AI 能理解"谁在做什么" → 电视作为中枢应聚合所有摄像头的场景语义，提供"家庭实时状态一屏总览"
- **自然语言自动化是智能家居的"App-less 体验"**：不再需要手动配置 if-this-then-that，说"快递放到门口告诉我"就能创建规则 → 电视大屏 + 语音遥控器是做自然语言自动化的最佳入口
- **低成本摄像头 + AI 自动化 = 全屋智能普及的关键**：$35 Walmart onn 摄像头就能做"红色 BMW 检测" → 智能家居从"有钱人的玩具"走向"普通家庭的标配"

### 7. 🐕 Nest Cam "Pet Memory" 宠物记忆：AI 认出你家毛孩子叫啥名字（🆕）

**来源/企业：** Google / 9to5Google (2026-06-02)

**摘要：**
Google Home 新增 Gemini 驱动的"Pet Memory"功能：用户通过"Ask Home"告诉 Gemini 宠物的名字和特征，之后摄像头通知不再说"一只狗在厨房走动"，而是**"Fido 在厨房走动"**。系统利用宠物面部识别区分多只宠物，减少误识别，提供个性化通知。需要 Google Home Premium Advanced 订阅（$20/月）。

同时，"Ask Home"语音查询扩展至全部支持地区（20个国家），德国首次加入 Gemini for Home 早期访问，支持德语。

**企划建议：**
- **"个性化命名"是 AI 体验从"工具感"到"家庭感"的关键一步**：让摄像头叫出你家狗的名字比"检测到动物"温暖 10 倍 → 国内摄像头品牌应跟进宠物识别+命名功能
- **宠物经济 $3000亿+ 市场，智能家居是天然入口**：宠物喂食器+宠物摄像头+宠物门禁+宠物健康监测 → 电视可作为"宠物看护面板"，展示宠物日常活动摘要
- **"Ask Home"全球扩展 = Gemini 语音助手的国际化进入快车道**：20个国家+德语上线 → 国内 AI 音箱品牌需加速多语言布局

### 8. 🕯️ Birdie Flame LED蜡烛 + Podium 净化器：创意设计驱动的智能家居产品线扩展（🆕）

**来源/企业：** Birdie / The Verge (2026-06-17)

**摘要：**
继 Birdie Pro 空气检测器（06-24初版第6条）后，Birdie 宣布扩展产品线推出两款新品：(1) **Birdie Flame LED蜡烛** ($49-69) — 不用真火的 LED 蜡烛，可用嘴吹灭、假装划火柴点燃，E-Ink 般的"假装真蜡烛"交互体验；(2) **Birdie Podium 净化器** — 设计成装饰性木质底座的空气净化器，融入家居而非像传统净化器"像台家用电器"。两款均预计11月出货，Kickstarter 众筹。

从"矿坑金丝雀死而复生"到"假装划火柴点蜡烛"，Birdie 的产品设计哲学一以贯之：**数据不可见、交互自然化、产品像家具**——这正是传统智能家居品牌最缺的设计思维。

**企划建议：**
- **"智能家居产品不该长得像电子设备"**：Birdie 的设计哲学值得国内品牌反思——把传感器藏进家具、让交互回归自然而然（吹灭蜡烛、鸟倒下），比在 App 里画图表高级得多
- **电视 UI 也应借鉴"数据不可见化"设计**：家庭环境数据（温度/湿度/CO2/AQI）不需要在电视上显示枯燥的仪表盘，可以设计"会呼吸的壁纸"——空气好时壁纸生机盎然，CO2 超标时壁纸凋零变色
- **"吹灭交互" = 智能家居需要更多物理直觉交互**：挥手、吹气、触摸、投掷——这些比点手机屏幕更自然的交互方式应该成为电视/音箱/灯具的标配
