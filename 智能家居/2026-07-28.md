## 二、最新技术

### 6. 🔥🔥 小米 Miloco v2026.7.17：多 Agent 运行时 + Gemini 适配器，开源AI管家加速成熟

**来源：** GitHub XiaoMi/xiaomi-miloco Releases (2026-07-17)
**链接：** https://github.com/XiaoMi/xiaomi-miloco/releases/tag/v2026.7.17

**摘要：** 小米 Miloco 2.0 在 7 月 17 日发布重大更新（117 commits、43 PRs、36K行新增），这是 Miloco 2.0 开源以来功能密度最高的一次发布。

**🔥 本次最关键的三个更新：**

#### (A) Hermes Agent 兼容层
定义了 `plugins//` 目录约定，使 Miloco 可以**宿主多个可插拔的 Agent 运行时**。这意味着：
- Miloco 不再是单一的 AI Agent，而是 Agent 的平台——第三方开发者可以编写自己的 Agent 运行在 Miloco 之上
- 类似于"智能家居的 App Store"——不同 Agent 负责不同场景（安防 Agent、节能 Agent、老人看护 Agent）
- 这对三星 SmartThings 是重要启示：SmartThings 也需要一个"Agent 插件架构"，而不只是一个 Routine 引擎

#### (B) Omni Provider Adapter + 多模型支持（含原生 Gemini 适配器）
- 统一的模型提供商适配层，支持从 UI 切换不同模型提供商
- **原生 Gemini 适配器**：支持 `media_resolution` 控制 + 关闭思考模式
- 这意味着 Miloco 不再绑定小米 MiMo 模型，可以跑在任何大模型上——开源生态的"去中心化"策略

#### (C) 双摄像头多通道双流感知
每路多镜头摄像头的每个通道都被提升为独立的一等公民摄像头，各自拥有独立的双流感知能力。这是多摄像头家庭的体验升级。

**其他关键更新：**
- **Tasks 升级为独立 Tab**：完整任务 CRUD + Agent 引导对话框
- **自动管理定时任务开关**：CLI + Web 双通道控制调度器启用/停用
- **Runtime omni_fps 热重载**：无需重建引擎即可实时调整感知帧率
- **多 IM 通知渠道**（OpenClaw 集成）
- **每摄像头独立麦克风开关**

**三星 SmartThings 竞争启示：**
- Miloco 的 Hermes Agent 层暗示了智能家居 AI 的未来架构——"平台型 Agent 系统"而非"单一 AI 助手"
- SmartThings 当前缺乏类似的 Agent 可扩展架构
- Miloco 的多模型适配器（可跑 Gemini/其他）降低了模型锁定风险——SmartThings 的 AI 能力目前仍绑定三星自研模型

- 旋转调节亮度/色温（精确控制，非只能开/关）

**行业意义：**
- IKEA 选择了 Matter over Thread 而非封闭生态——这是 Matter 标准"设备端"成功的标志性事件

### 📊 三星 SmartThings 竞争视角

1. **Tesla Home 的威胁：能源是智能家居的"杀手场景"**——Tesla Home 将能源管理从一个"SmartThings Energy 子功能"升级为一个独立品牌品类。三星必须在 Marketing 层面提升 SmartThings Energy 的品牌认知度，而不只是把它藏在 App 里。

2. **Miloco 的 Hermes 层暗示了正确架构**——SmartThings 需要一个 Agent 插件框架，允许第三方开发者在 SmartThings 之上构建场景 Agent（而不是只能设置 Routine）。当前 SmartThings 的 Routine 引擎是"规则"而非"Agent"，差距正在扩大。

3. **LG 的 B2B 精装房模式是直接竞争**——LG 与三星在韩国房地产市场的智能家电争夺战已经开始。SmartThings Pro 需要加速推出面向开发商的完整解决方案（不只是酒店/商业，住宅精装也是关键）。

4. **IKEA 合作验证了"去Hub化"策略**——SmartThings 让用户不需要 IKEA Hub 就能用 IKEA 设备，这是一个很好的用户价值主张。继续保持开放生态策略。

5. **扫地机器人价格血战 → 自研扫地机并不紧迫**——与其在价格战中推出自有品牌扫地机，SmartThings 应优先与头部品牌建立数据互通（地图/状态/清洁记录），将扫地机作为"移动传感器平台"接入全屋智能。

6. **能源AI助手是 2026 下半年的核心战场**——Tesla/SolaX/Sigenergy 三家同时发布能源AI，SmartThings Energy 的"AI Energy Mode"需要在用户体验上大幅升级（加入自然语言交互 + 决策解释），而不能只是后台省电。
