### 1. 🤖 乐享科技"元点Zeroth"：5亿融资+3万台订单，家庭具身智能新物种降临

**来源/企业：** 乐享科技 / 环球网、新浪财经 (2026-07-02)

**摘要：**
7月2日，苏州乐享科技正式宣布完成近5亿元Pre-A轮融资（蚂蚁集团领投，吉利资本、三七互娱跟投），累计融资达10亿元，并发布家庭具身智能品牌 **"元点Zeroth"**。这是中国家庭机器人赛道迄今最大规模的单笔融资之一。

**关键数据：**
- 在手订单已突破 **3万台**，2026年上半年营收同比增长 **600%**
- 研发人员占比超80%，核心成员来自清华、浙大、中科院、宾大、CMU
- 已完成60余项原创性专利布局，发明专利占比超50%
- 全栈自研六大核心技术：关节模组、轻量化机械臂、VLA、具身通用模型、本体结构、意识仿生模型

**产品矩阵（五款机器人）：**
- **M1**（小型人形陪伴机器人）——全球首个进入家庭的具身智能机器人，也是全球首个接入 **OpenClaw** 的人形机器人
- **Jupiter**（全尺寸人形机器人）——定位家庭伙伴
- **N1**（家庭协作机器人）——全球首创异构机械臂方案
- **W1**（户外履带式机器人）
- 迪士尼IP独家合作款瓦力

**核心差异化理念：** "共生"——机器人不是工具，而是人类的"智能镜像"与"镜像伙伴"。元点Zeroth 明确反对将机器人定位为"劳动力替代"，转而强调"陪伴+共同成长"。

**企划建议：**
- **元点Zeroth 接入 OpenClaw = 家庭AI Agent 生态的关键里程碑**：这是人形机器人首次与开源AI Agent框架打通 → 电视品牌的AI助手可以考虑通过OpenClaw/Miloco 2.0等Agent框架接入机器人，实现"电视AI + 机器人执行"的协同
- **M1是全球首个进入家庭的具身智能产品，电视品牌应立即研究其交互模式**：M1作为"进入家庭"的机器人，其语音交互、场景感知、自主导航能力直接影响用户对"家庭AI"的认知 → 电视需要思考：当机器人能在家里走动、看护、交流时，固定位置的"智能屏"如何重新定位？
- **蚂蚁+吉利+三七互娱的资本组合 = 家庭机器人从"科技叙事"到"消费场景"的跃迁**：金融支付（蚂蚁）+出行场景（吉利）+娱乐内容（三七互娱）→ 暗示元点Zeroth未来的场景可能不只是"做家务"，而是支付、出行联动、娱乐陪伴 → 电视品牌可提前探索"电视+机器人+内容"的家庭娱乐场景
- **"迪士尼IP瓦力" = IP联名是家庭机器人破圈的关键路径**：元点Zeroth用瓦力IP降低了用户对新品类的情感门槛 → 电视品牌的AI产品也可以考虑IP合作（如儿童模式中的卡通角色交互）

### 2. 📡 Matter 1.6 正式发布：NFC轻触配网 + Joint Fabric多生态共享 + 温控器AI建议

**来源/企业：** CSA 连接标准联盟 / Forbes、CSA官网 (2026-06-18)

**摘要：**
在6月18日 CSA "Unify"年度大会上，Matter 1.6 正式发布。与1.5/1.5.1聚焦摄像头等新设备类型不同，**Matter 1.6 是"功能型"版本**，引入三大核心新能力：

**① NFC 全流程配网（NFC-Based Commissioning）：**
- 设备即使未完全通电，也能通过 NFC 双向通信完成全流程配网
- 不再依赖蓝牙辅助配网，不再需要扫二维码 → 用手机"碰一下"即可添加设备
- 大幅简化安装流程，尤其利好批量部署（如酒店/公寓全屋智能项目）

**② Joint Fabric（联合网络）：**
- 允许多个智能家居生态系统（如同时使用 HomeKit + Google Home + Alexa）**共享一个"联合网络"**
- 管理员可以独立添加/移除，设备只需为一个 Joint Fabric 分配一个 Fabric 配额
- 真正解决"一个设备同时属于多个App"时的配额冲突问题

**③ 温控器智能建议机制（Thermostat Intelligent Suggestion）：**
- 建立统一的温控建议交互协议
- 系统可以向温控设备推送优化建议（如"建议将夜间温度调低2度以节能"），但**设备端自主决定是否采纳**
- 结合用户偏好学习，避免AI"替用户做决定"引发的抵触

**企划建议：**
- **NFC配网 = "碰一碰连设备"将成为智能家居标配体验**：类比AirDrop让文件传输变得"碰一下就行"，NFC配网让添加设备同样简单 → 电视品牌的智能家居App必须支持NFC配网，并教育用户"碰一碰加设备"
- **Joint Fabric = 真正的跨生态共存终于到来**：这意味着一个Matter灯泡可以同时出现在HomeKit和米家App中，不用"二选一" → 电视品牌应利用Joint Fabric实现"在电视上同时管理HomeKit和自家生态设备"，成为跨生态中枢
- **温控器AI建议 = Matter首次引入"AI建议权"概念**：系统可以建议但不强制，这是一个微妙的平衡——电视品牌的AI家居中枢应采用同样思路："AI建议+用户确认"而非"AI自动执行"，避免信任危机
- **Matter 1.6 + matter.js = 协议层+工具层的双层推进**：上期的matter.js是工具链革命，Matter 1.6是协议层革命，两者叠加意味着Matter正在从"连接标准"升级为"智能家居操作系统" → 电视品牌应加速Matter认证，抢占"智能家居OS"时代入口

- **音频检测 = 摄像头AI从"看"到"听"的升级**：识别婴儿哭声、玻璃破碎声对家庭安全至关重要 → 电视品牌如果做摄像头/AI中枢，应标配"视听双模态"检测能力

- Prime会员免费，非会员£19.99/月（英国）或$19.99/月（美国）

**与Gemini的对比（The Ambient深度评测结论）：**
- Alexa+ 深度嵌入Amazon生态（Ring摄像头/Prime Video/购物），更偏向"消费+安防"
- Gemini 横跨Google搜索/Gmail/YouTube/Android/Google Home，更偏向"知识+全家服务"
- 智能家居设备控制方面，两者已非常接近

**企划建议：**

- **97%设备兼容 = AI升级无需换硬件的"iOS模式"值得学习**：用户不需要花钱买新设备就能享受AI升级，这极大降低了用户流失 → 电视品牌在做AI功能时，应优先考虑"OTA升级"而非"只有新硬件才支持"
- **悄悄升级的争议 = AI部署的"透明度"是信任基础**：用户对"被升级"的不满提醒我们：AI功能变更必须获得用户知情同意 → 电视品牌的AI功能更新应设有明确的"预览/同意/回退"机制
- **Alexa+ vs Gemini = 智能家居AI正在形成"消费电商"和"知识服务"两条路线**：电视品牌的AI定位应在两者之间找到差异化——"家庭娱乐+生活服务"可能是一个切入点

### 10. 🔍 2026全屋智能四大路线对比：从"被动响应"到"主动服务"的分水岭

**来源/企业：** IT之家 / 新京报 / 多家媒体 (2026-07-03)

**摘要：**
7月3日，IT之家发布《2026年全屋智能怎么选》深度评测，系统对比了四条主流路线：

| 路线 | 代表企业 | 核心优势 | 核心短板 |
|------|----------|----------|----------|
| **高性价比生态** | 小米米家 | 800+SKU生态/1.5-2万元/DIY灵活 | 依赖云端/断网失效90%/品控波动/售后48小时 |
| **连接稳定前装** | 华为鸿蒙智家 | PLC通信/本地联动/传感器强 | 生态封闭/第三方兼容<40%/仅适新房前装 |
| **高端隐私路线** | Apple HomeKit | 体验统一/隐私完善/全家桶联动 | 品类少/门槛高/欧美逻辑/难适国内 |
| **主动智能一体化** | 海尔智家/美的 | L4主动智能/AI之眼/全品类/十年服务 | 投入较高/专注前装 |

**核心结论：**
- 2026年全屋智能已从"能联网控制"升级为**"能主动服务"的竞争**
- 消费者选择的不再是"哪个品牌设备多"，而是**"哪个AI大脑更懂我"**
- 主动智能等级（L1-L4）正在成为行业新标准（海尔Seeker套系已通过新国标L4认证）
- **断网应对能力**（本地计算 vs 纯云端）是中国市场的关键差异化维度

**企划建议：**
- **"主动智能"= 全屋智能的下一个标准战场**：四家路线虽然技术路径不同，但终点都是"主动服务" → 电视品牌的AI战略应以"主动智能"为北极星指标——多久能记住用户习惯、多准能预判需求、多快能自主决策
- **中国市场两大变量：断网可用 + 方言识别**：Google/Alexa最怕的两件事——中国用户对隐私的敏感性（要求本地计算）+ 中国家庭的语言多样性（方言）→ 电视品牌如果做好"离线AI + 方言交互"，就有与Google正面竞争的差异化武器
- **PLC技术的"前装困境"= 后装方案的机会**：华为PLC需要预埋线管 → 美的/小米的无线方案可以覆盖存量房市场 → 电视品牌应优先开发"不砸墙、不走线"的无线智能方案
- **L4主动智能认证 = 行业标准化趋势**：随着海尔率先通过新国标，未来"你家智能家居是L几？"可能成为消费者选购时的标准问题 → 电视品牌应关注国标进展，提前准备认证
