### 1. RGB-Mini LED Q1实锤 — 海信独占七成，年度40-50万台确定性增强
**来源/企业：** 洛图科技 / 海信 / TCL / 三星 / ZNDS（6月15日）  
**摘要：** Q1全球RGB-Mini LED电视销量约2.4万台，已超2025全年总量；累计销量近5万台。核心数据：中国市场占全球89.4%销量；海信Q1份额超70%（绝对领先）、TCL接近20%、三星追赶中。尺寸结构：85"占36.5%最主流、75"从去年16.3%跃升至24.5%、100"+超大屏约31.9%。全年预测40-50万台。品牌扩容：Sony/长虹/飞利浦/创维今年陆续加入RGB赛道。  
**企划建议：** 中国品牌（尤其海信）在RGB-Mini LED领域的技术溢价窗口明确——海信70%+份额说明先行者优势巨大。建议：①如果进入RGB赛道必须选择差异化定位（如75"主力/100"+高端，避免与海信85"正面硬刚）；②Sony今年入局将加速消费者认知，2026年40-50万台市场只是开端，2027年可能翻倍至80-100万台，供应链（RGB LED芯片/驱动IC）需提前锁定；③75"份额增速最快（+8.2pct），次旗舰RGB产品可先攻75"。

### 2. LG否认出售电视业务 — "中国收购韩系"叙事告一段落，但产业合作在深化
**来源/企业：** LG电子 / 海信 / ZNDS（6月16日）  
**摘要：** LG官方回应"可能将电视业务出售给海信"的传闻：无事实依据，纯属猜测。海信方面此前也已否认收购计划。但LG承认近期与海信、TCL等中国厂商确实频繁交流，业内人士认为这更可能是供应链/技术合作层面。LG继续推动OLED电视业务，海信则聚焦RGB-Mini LED，双方核心路线并不一致。LG在OLED面板/整机上仍保有完整产业链优势。  
**企划建议：** ①虽然收购被否认，但"中韩产业合作加深"本身是确定趋势——可关注LG是否会像Sony与TCL合作那样，与中国厂商在OLED面板供应/代工层面建立合作；②LG OLED + 中国品牌Mini LED的技术路线分化将持续，短期内"一方吃掉另一方"不会发生，但中长期OLED与Mini LED的成本差缩小将决定竞争格局；③中国企业"出海收购"叙事需要更审慎——政策/品牌/工会障碍比市场想象的大。

### 3. Sony Bravia 6 OLED中端线曝光 — 48-83"覆盖，用"成本可控WOLED"抢夺中端
**来源/企业：** Sony / 海外认证数据 / ZNDS（6月16日）  
**摘要：** Sony继Bravia 7 II/8 II/9 II旗舰系列后，计划推出全新Bravia 6系列中端OLED，覆盖48-83"多尺寸。关键策略：采用LG Display WOLED面板（可能为OLED SE成本优化版），非QD-OLED或Tandem方案，以此控制成本。预计搭载Pentonic 800芯片、HDMI 2.1、杜比视界2。5月8日已通过Wi-Fi联盟认证，可能轻量上市。市场意义：Sony正在用"品牌溢价+中端面板"组合拳，在55-65"区间与Mini LED正面竞争。  
**企划建议：** ①Sony用"成本可控OLED"打中端，说明OLED面板成本正在下移——Mini LED在55-65"的价格优势窗口可能比预期更短；②WOLED成本下降利好整个OLED阵营，LG Display可能扩大对外供货，国内品牌若想上OLED产品线，现在是与LGD谈判窗口期；③Sony"全数字化命名+全产品线覆盖"策略值得借鉴——清晰的产品矩阵更容易建立用户认知。

### 4. BOE成都B16 8.6代IT AMOLED量产 — 中国高端面板"双轨并进"
**来源/企业：** 京东方 / OLED-Info（6月17日）  
**摘要：** 京东方在成都举行B16 8.6代IT AMOLED产线量产仪式，首款产品为14" 2.8K笔电OLED面板。客户覆盖联想/荣耀/vivo/OPPO/中兴/小米/传音/Nothing等。这是全球第二条量产8.6代OLED线（三星A6后），标志着中国从手机OLED向IT OLED跨越。此前BOE已因"AI算力+康宁合作"概念被重估为泛半导体平台（5月21-22连板涨停）。  
**企划建议：** ①BOE在OLED领域的产能扩张将间接影响电视面板——IT OLED技术积累可反哺大尺寸OLED/印刷OLED技术；②关注BOE合肥8.6代线（B20，规划中）是否切入电视OLED，这将改变全球OLED TV面板被LG Display垄断的格局；③BOE的"泛半导体/AI算力平台"估值逻辑，说明面板厂正在脱离纯周期股定位，对电视品牌采购策略有影响（面板厂议价能力增强）。

### 5. Samsung Display 40,000nit OLED微显示屏 — 亮度一年翻倍，AR眼镜加速
**来源/企业：** Samsung Display / AWE USA 2026 / OLED-Info（6月17日）  
**摘要：** Samsung Display在AWE USA 2026展示1.3"直接发光OLED微显示屏，亮度达40,000nit（同比翻倍），为SDC迄今最亮OLED微显。公司称其为RGB OLEDoS技术。同时展示0.62"版本AR眼镜原型。SDC计划2028年量产RGB OLEDoS产线。目前仅次于INT Tech的100,000nit记录。  
**企划建议：** ①OLED微显亮度突破40K nit对AR/VR是质变级信号——户外可用的消费级AR眼镜更近了；②电视品牌需关注"AR眼镜替代电视"的长远威胁——如果2028-2030年AR眼镜成熟，个人大屏观影的终端将从电视转向眼镜，电视需强化"家庭共享场景"定位（体育/家庭影院/多人互动）作为护城河；③短期内微显技术不直接影响电视，但RGB OLEDoS技术积累可能反哺大尺寸直接发光OLED。

### 6. 维信诺（Visionox）深度分析 — 中国OLED"第二梯队"的技术野心与财务困境
**来源/企业：** Visionox / 合肥政府 / OLED-Info（6月17日）  
**摘要：** Visionox是中国AMOLED第二梯队，全球智能手机AMOLED市占率约10%，累计出货2.4亿片OLED。但2025年仍在亏损，累计净亏损约$12亿。2025年底合肥政府注资$4.1亿成为最大股东。公司在建全球首条8.6代ViP（掩模版免）OLED产线，斥资$76亿，技术路线独特。这是一家"技术领先但财务脆弱"的典型中国面板企业——政府背书+自研技术+持续烧钱。  
**企划建议：** ①Visionox的ViP技术（无掩模版OLED蒸镀）如果成功，可能动摇Samsung Display的FMM（精细金属掩模）垄断——这是电视OLED面板成本下降的潜在催化剂；②关注合肥政府对Visionox的控制力增强趋势——政府主导的面板产业整合可能改变竞争格局；③如果Visionox的8.6代线2027-2028量产，中国将拥有三条8.6代OLED线（BOE/天马/Visionox），IT OLED产能过剩可能使面板价格加速下降，利好电视品牌采购。

### 7. 海信世界杯体育营销10城联动 — 体育赛事+RGB-Mini LED绑定，线下体验驱动高端转化
**来源/企业：** 海信 / 2026世界杯 / ZNDS（6月13日）  
**摘要：** 海信作为FIFA世界杯连续三届官方赞助商，6月13日起在全国10城同步开设世界杯主题店，杭州西溪印象城为首发。核心打法：116"全球最大RGB-Mini LED UX2026真机体验+世界杯裁判同款显示技术背书+跨界品牌联动（可口可乐/蒙牛/阿迪达斯/瑞幸/顾家家居/芝华仕）。杭州数据亮眼：1-5月线下整体市占率34.7%，高端47.8%，98"+超大屏45.5%，U7S Pro销额TOP1。顾家家居"青云座"智能单椅与海信深度融合，打造"家居+家电"沉浸观赛。  
**企划建议：** ①体育营销绑定显示技术是海信的经典打法（欧洲杯→世界杯），值得复制：核心是用"裁判同款/赛事官方"建立技术权威性；②"家居+家电"跨界场景（顾家芝华仕合作）是很好的用户触达创新——电视购买决策与家居装修天然相关，可在红星美凯龙/居然之家设体验区；③10城主题店模式验证了"线下超大屏体验→线上转化"路径，85"+大屏电视必须解决"线上看不到效果"的信任问题。

### 8. 高通AI智能体趋势 — 可穿戴设备分流"个人屏"，电视需重定义"家庭屏"价值
**来源/企业：** 高通 / CNBC / ZNDS（6月17日）  
**摘要：** 高通CEO Cristiano Amon表示AI智能体将成为下一代交互核心，可能重塑App形态。关键判断：智能手机不再是唯一数字中心，智能眼镜/手表/耳机/胸针等可穿戴设备将成为AI服务触达用户的重要入口。高通推进40+款AI可穿戴设备设计，智能眼镜出货量预计从数千万级→数亿级。OpenAI收购Jony Ive硬件公司io，AI企业主动布局终端入口。可穿戴设备收集的情境数据规模将远超当前AI训练数据量。  
**企划建议：** ①可穿戴AI设备崛起对电视是"场景再定义"的契机：当"个人屏"（手机/眼镜/手表）越来越强，"家庭共享屏"（电视）必须差异化——强化多人协同场景（家庭游戏/亲子教育/聚众观赛），而非与个人设备比便利性；②电视的AI能力应该从"个人助手"转向"家庭助手"——识别房间内多人、区分大人/小孩内容、管理家庭日程，这些是个人设备做不到的；③电视芯片需要为"多AI智能体协同"做准备——未来的家庭AI不是电视内置一个语音助手，而是电视作为算力节点协调多个可穿戴设备。

### 9. 世界杯驱动"投屏生态"爆发 — 小红书/咪咕抢滩大屏，第三方投屏工具成基础设施
**来源/企业：** 小红书 / 咪咕 / 当贝 / ZNDS（6月11-15日）  
**摘要：** 2026世界杯（6月12日-7月20日）催生新一代大屏观赛生态：小红书首次成为世界杯持权转播商（104场免费直播4K），咪咕作为传统体育平台持续深耕，双方均支持投屏到电视大屏。当贝投屏等第三方工具成为关键基础设施——支持精准投屏（仅投视频不投手机屏）、4K无损、低延迟。用户行为变化：越来越多的人用手机APP找内容（小红书/咪咕）→投屏电视观看，而非直接在电视上打开APP。  
**企划建议：** ①"手机找内容+电视看内容"已成为主流行为范式——电视OS不应只关注"电视端应用生态"，而是优化投屏体验（一键投屏/断点续投/多设备切换）；②体育赛事是电视最高频的"不可替代场景"，建议产品定义阶段就将体育观赛体验纳入核心用例（低延迟模式/运动补偿/多视角）；③小红书成为世界杯转播商的信号——内容平台正在向上游渗透，未来可能出现"抖音/TikTok电视版"直接竞争传统电视OS内容生态。

### 10. 面板供应链动态汇总 — BOE量产8.6代、Visionox困境、Omdia下调预期
**来源/企业：** Omdia / OLED-Info / ZNDS（6月15-17日）  
**摘要：** 供应链三件大事：①BOE B16 8.6代IT AMOLED量产（利好中国面板话语权）；②Visionox虽持续亏损但获政府$4.1亿注资继续押注ViP技术（赌注式投资）；③Omdia下调2026年全球显示面板出货预期（终端需求走弱+成本压力）。结合前期Runto数据（面板价格Q2持平），整体判断：高端面板（OLED/Mini LED）供给扩张但终端需求承压，面板厂进入"技术升级换利润"周期。  
**企划建议：** ①面板需求走弱+供给扩张=下游品牌方议价能力短期增强——Q3-Q4可争取更好的面板采购价格；②Omdia下调预期是宏观经济信号，电视品牌需要做好"以质换量"准备（整体出货可能下滑，但高端占比提升）；③关注Visionox的ViP技术进展——如果2027年底验证成功，2028年可能改写OLED成本曲线，届时Mini LED的高端定位将受冲击。
